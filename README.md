# 你好，我是 cwyf 👋

我在做独立游戏，也把制作过程中反复遇到的问题整理成可复用的工具和工作流。

目前主要在探索 **Godot、风格化 3D 场景和 AI 辅助制作**。我更关心工具能否落到真实工程里：保留创作方向、解决具体问题，并用实机结果检验修改。

## 开源项目

### [Godot Moebius Rendering](https://github.com/cwyf/godot-moebius-rendering)

莫比斯启发式 Godot 美术工作流与 AI 代理 skill。涵盖程序化模型的机械感、手绘线稿、色块阴影、近粗远细、场景细节，以及动态画面的清晰度检查。

- 从真实项目检查开始，支持先在副本中修改。
- 线稿、材质、模型和场景构造分别诊断，再统一效果。
- 附带经过 Godot Forward+ 项目验证的描边着色器参考。
- 使用 MIT 许可证；欢迎反馈、复用和贡献。

它是一套工作流和参考实现，不是任意游戏的一键风格转换器。

[查看项目与使用方法 →](https://github.com/cwyf/godot-moebius-rendering)

## 制作中的原则

保留已经确定的创作方向；先找到问题来源，再增加效果；同时检查静态画面与连续运动；把有效的方法整理下来，方便下一次复用。
